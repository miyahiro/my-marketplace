# 引き継ぎメモを作る

利用者が渡した変更メモを、次の担当者に渡す引き継ぎメモに整える。

## 手順

1. 利用者が渡した変更メモだけを材料にする。リポジトリのファイルを読んだり、書き換えたりしない。
2. 次の3項目に分けて書く。
   - 目的
   - 変更点
   - 確認事項
3. 変更メモに書かれていない項目は、推測せずに「記載なし」と書く。
4. 実施していない確認を、実施済みとして書かない。

## 出力の形

### 目的

（変更の目的。書かれていなければ「記載なし」）

### 変更点

（変更した内容を箇条書きで）

### 確認事項

（次の担当者が確認すべきこと。未実施の確認があれば、未実施と書く）

### 補足

（次の担当者への補足事項を書く。補足事項がなければ「なし」と書く。）
